# MeshTwin

## The problem
**Who has it:** An engineer designing a network of battery-powered sensors.
**What goes wrong today:** Nobody knows how long the batteries will last, or which nodes fail first, until the network is deployed.
**What this project does:** Simulates hundreds of sensors with packet loss and an energy model, then predicts each node's battery life.
**How I know it works:** Predicted lifetimes land within 10% (median error) on network layouts the model never saw.
